# Вычисление определителя матрицы

## Описание

Программа вычисляет определитель квадратной матрицы размером N × N.
Размер матрицы и её элементы считываются из файла `input.txt`.
Результат выводится в консоль.

## Алгоритм

Для вычисления определителя используется метод Гаусса.

1. Для каждого столбца выбирается ведущий элемент с максимальным модулем.
2. При необходимости строки меняются местами.
3. Выполняется исключение элементов ниже главной диагонали.
4. Определитель вычисляется как произведение элементов главной
   диагонали с учётом знака перестановок строк.
5. Если ведущий элемент близок к нулю, определитель считается равным нулю.

## Входные данные

Файл `input.txt` содержит:

- В первой строке — целое число N, размер матрицы.
- В следующих N строках — по N чисел, разделённых пробелами.

## Пример входных данных

```text
3
1 2 3
4 5 6
7 8 10
```

## Пример результата

```text
-3
```

## Требования

- Python 3.8 или выше.
- Сторонние библиотеки не требуются.

## Запуск программы

1. Поместите входные данные в файл `input.txt`.
2. Откройте терминал в директории проекта.
3. Выполните команду:

```bash
python main.py
```

## Запуск модульных тестов

```bash
python -m unittest -v
```

## Сложность алгоритма

- Временная сложность: O(N³).
- Пространственная сложность: O(N²).
